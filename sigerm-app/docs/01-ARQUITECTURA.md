# Arquitectura de SIGERM

## Arquitectura General

SIGERM sigue una arquitectura multicapa basada en Next.js y Supabase.

```
Usuario
      │
      ▼
Interfaz (Next.js)
      │
      ▼
API Routes
      │
      ▼
Supabase
      │
      ▼
PostgreSQL
```
